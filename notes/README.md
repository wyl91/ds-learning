# 学习笔记

按章节建 markdown 文件，命名 `ch01_线性表.md`。

## 记什么

**不要**抄书。抄书没用。只记三类东西：

1. **自己踩的坑** —— 比如"循环队列判断满条件写错了，因为……"
2. **手工推演过程** —— 快排一趟、KMP 的 next 数组、AVL 旋转，手写一遍比看十遍强
3. **一句话总结** —— 这个结构解决了什么问题、代价是什么
