# Ch02 栈和队列

## 要掌握的

| 结构 | 特性 | 典型题 |
|---|---|---|
| 顺序栈 SqStack | 后进先出，top 指针 | 括号匹配、表达式求值 |
| 链栈 LiStack | 用链表实现，不存在栈满 | 递归转非递归 |
| 循环队列 SqQueue | front/rear，用取模实现环形 | 约瑟夫环、BFS |
| 链队列 LinkQueue | front/rear 双指针 | 任务调度 |

## 关键坑

- **循环队列判空判满**：牺牲一个存储单元 —— `front == rear` 为空，`(rear+1)%MAXSIZE == front` 为满。
- **栈的出入序列合法性**：入栈序列固定时，判断出栈序列是否合法，用模拟法。
- 队列别用普通数组硬写，`rear` 到头就"假溢出"了。
