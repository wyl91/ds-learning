# Ch03 串与数组

## 要掌握的

- **KMP 算法** —— 这是本章唯一真正的重点。核心是 `next` 数组：模式串自己和自己匹配，算出失配时该退到哪。
- 暴力匹配 O(m*n) → KMP O(m+n)，差距在"主串指针不回退"。
- 稀疏矩阵的三元组表示、快速转置。
