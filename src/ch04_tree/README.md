# Ch04 树与二叉树

## 要掌握的

- **二叉树遍历**：先序 / 中序 / 后序（递归 + 非递归），层序（用队列）
- **由遍历序列还原二叉树**：中序 + 先序 / 中序 + 后序 / 中序 + 层序，三种都能唯一确定
- **线索二叉树**：把空指针利用起来指向前驱/后继
- **哈夫曼树**：带权路径长度最小，贪心建树 + 哈夫曼编码
- **二叉排序树 BST**：左 < 根 < 右，查找 O(log n) 平均
- **平衡二叉树 AVL**：LL / RR / LR / RL 四种旋转
- **B 树 / B+ 树**：知道为什么数据库索引用它（减少磁盘 I/O 次数）

## 关键坑

- 只知道先序 + 后序，**还原不出唯一二叉树**。必须有中序。
- 非递归后序遍历是最难写的：要加 `lastVisited` 指针判断右子树是否已访问完。
