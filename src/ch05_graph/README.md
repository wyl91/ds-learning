# Ch05 图

## 要掌握的

**存储**
- 邻接矩阵：O(V²) 空间，判断两点是否相邻 O(1)
- 邻接表：O(V+E) 空间，稀疏图首选

**遍历**
- DFS：递归或栈，用 `visited[]` 防重复
- BFS：队列，天然求**无权图最短路径**

**最短路径**
- Dijkstra：单源，无负权边，贪心 + 松弛
- Floyd：多源，三重循环，代码极短
- Bellman-Ford：能处理负权边，能判负环

**最小生成树**
- Prim：按点扩展，适合稠密图
- Kruskal：按边排序 + 并查集，适合稀疏图

**拓扑排序**
- AOV 网，每次取入度为 0 的点。能排完说明无环。

## 建议文件

- `01_graph_traverse.c` — 邻接表 + DFS/BFS
- `02_dijkstra.c` — 最短路径
- `03_kruskal.c` — 最小生成树（含并查集）
- `04_toposort.c` — 拓扑排序
