# Ch06 查找

## 要掌握的

| 方法 | 前提 | 平均时间 | 备注 |
|---|---|---|---|
| 顺序查找 | 无 | O(n) | 加哨兵可少一次比较 |
| 折半查找 | **有序** | O(log n) | 判定树高度 |
| 分块查找 | 块间有序 | O(√n) | 索引表 + 块内顺序 |
| 散列表 | 哈希函数 | O(1) | 重点是**冲突处理** |

## 散列表重点

- **除留余数法**：`H(key) = key % p`，p 取小于表长的最大质数
- **开放定址**：线性探测（会堆积）、平方探测
- **拉链法**：同义词挂链表
- **装填因子 α = 元素数 / 表长**，α 越大冲突越多
- 会算 **ASL（平均查找长度）**——考研/期末必考计算题
