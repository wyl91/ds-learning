# Ch07 排序

## 复杂度速查表（背下来）

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 特点 |
|---|---|---|---|---|---|
| 直接插入 | O(n²) | O(n²) | O(1) | ✅ | 基本有序时很快 |
| 希尔排序 | O(n^1.3) | O(n²) | O(1) | ❌ | 插入排序的增量版 |
| 冒泡 | O(n²) | O(n²) | O(1) | ✅ | 教学用 |
| 快速排序 | O(n log n) | **O(n²)** | O(log n) | ❌ | 最坏出现在已有序+固定基准 |
| 简单选择 | O(n²) | O(n²) | O(1) | ❌ | 交换次数最少 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | ❌ | 只用数组，不用递归 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | ✅ | 唯一稳定的 O(n log n) |
| 基数排序 | O(d(n+r)) | 同左 | O(r) | ✅ | 非比较排序 |

## 必须能手工模拟的

- 快排一趟的划分过程（Lomuto / Hoare 两种分区）
- 堆的**建堆**过程（从 n/2 往下筛）
- 归并的 merge 过程

## 建议文件

- `01_insert_sort.c` — 直接插入 + 希尔
- `02_quick_sort.c` — 快排（含随机化基准）
- `03_heap_sort.c` — 堆排序
- `04_merge_sort.c` — 归并排序
- `05_radix_sort.c` — 基数排序

每个文件里都写一个 `checkSorted()` 自动校验结果，别靠肉眼看输出。
